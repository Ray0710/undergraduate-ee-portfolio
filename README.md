# Undergraduate Electrical Engineering Portfolio

A capstone and four course projects from my undergraduate electrical engineering studies at National Taiwan Ocean University. Each page describes the design, my work, and the available verification evidence.

| Project | Tools | Evidence |
| --- | --- | --- |
| [Fixed-point Gaussian noise generator](projects/fpga-gaussian-noise-generator/) | Verilog, SystemVerilog, Vivado, MATLAB | RTL, testbenches, simulated distribution, Arty S7-25 post-route timing, and a 60-second board capture |
| [Verilog parking-lot controller](projects/verilog-parking-lot-controller/) | Verilog, finite-state machines, RTL simulation | Architecture diagram and testbench waveform |
| [TTL LED handball game](projects/ttl-led-handball/) | 74LS logic, MAX+PLUS II, circuit prototyping | Schematic, timing simulation, and soldered board |
| [MSP430 single-digit calculator](projects/msp430-single-digit-calculator/) | MSP430FR2355, Energia, ADC, GPIO interrupts | Archived firmware and display interface |
| [MATLAB cart-pendulum simulation](projects/matlab-cart-pendulum/) | MATLAB, state-space modeling, feedback control | State trajectories and an animation frame |

The FPGA page separates the undergraduate design from the later Arty S7-25 implementation. Simulation, implementation reports, and physical prototype evidence are identified on the relevant project pages.
